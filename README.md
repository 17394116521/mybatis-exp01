# 实验一：AI赋能 MyBatis 与 MyBatis-Plus 环境搭建及CRUD实操
## 📌 实验信息
- 环境：IDEA、Maven3.9.6、JDK、MySQL、MyBatis
- 版本管理：Git+GitHub，分阶段提交保留开发时间线

## 📋 实验目的
1. AI辅助搭建MyBatis项目，解决依赖、配置报错问题
2. 掌握MyBatis CRUD增删改查开发
3. 使用Git版本控制，留存完整开发提交记录

## 📁 项目结构
mybatis-exp01
├── src/main/java        # 实体类、Mapper 接口
├── src/main/resources   # 配置文件、Mapper 映射 XML
├── src/test/java        # JUnit CRUD 测试代码
├── pom.xml              # Maven 依赖
└── .gitignore

## ▶ 运行步骤
1. IDEA导入项目，配置Maven与JDK
2. MySQL建表，修改数据库连接账号密码
3. Maven加载依赖，运行JUnit测试CRUD

## 🕒 Commit提交时间线
1. commit1：初始化Maven项目，导入MyBatis、MySQL驱动依赖
2. commit2：设计数据表，编写实体类
3. commit3：编写Mapper接口、XML映射与MyBatis主配置
4. commit4：基础查询功能编码与测试
5. commit5：完成全部CRUD增删改查JUnit测试
